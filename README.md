Personal Finance Manager
Month 1: Python Programming Mastery Internship Task
A comprehensive personal finance management system built with Python. This project demonstrates mastery of object-oriented design, file handling, data persistence, and a modular code structure.

                             Project Goals
Expense Tracking: Create, view, and manage financial records.

Data Analysis: Generate category-wise summaries and spending patterns.

Data Persistence: Ensure data is stored safely in CSV format.

Data Security: Implement backup and restore functionalities.4

                        Project Structure
The code is organized into separate modules for better maintainability and organization:

main.py: The entry point and interactive menu system.

expense.py: Defines the Expense class and its attributes (amount, category, date, description).

file_manager.py: Handles all CSV read/write operations and data backups.

reports.py: Contains logic for calculating totals, averages, and category summaries.

data/: Folder containing the persistent expenses.csv file.

                           Features & Technical Requirements
Object-Oriented Design: Uses classes to represent financial data.

Interactive CLI: A user-friendly menu system for navigation.

Error Handling: Comprehensive validation for user inputs to prevent crashes.

Report Generation: Automatic calculation of total and average expenses.

Backup & Restore: Functionality to protect data against accidental loss.

                         Setup & Usage
Requirements: Ensure Python 3.x is installed.

Installation: Place all .py files in the same directory.

Execution: Run the command python main.py in your terminal.

Data Management: Use the menu options (1-6) to add data, view reports, or perform backups.
